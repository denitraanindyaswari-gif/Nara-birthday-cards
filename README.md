# Birthday Web for Nann ♡

A small interactive birthday website made with plain HTML, CSS, and JavaScript.

## Files
- `index.html` — page structure and text
- `style.css` — dreamy sky-blue design
- `script.js` — buttons, section navigation, and photo popups
- `images/` — uploaded memories

## Deploy
Use GitHub Pages:
1. Create a GitHub repository.
2. Upload everything in this folder.
3. Go to Settings → Pages.
4. Source: Deploy from a branch.
5. Branch: `main`, folder: `/ (root)`.
6. Save and wait for the site to publish.
